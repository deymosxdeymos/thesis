	\large \bfseries \MakeUppercase{Abstract}\\
	\normalsize \normalfont {\thetitleEN}\\
	\normalsize \normalfont {\theauthor}\\
	\bigskip
	
	\normalsize \normalfont \justifying \singlespacing
	Collaborative learning is a vital component in modern education for developing students' interpersonal and problem-solving skills. However, manual group formation often results in skill imbalances, interpersonal conflicts, and unequal participation. This research develops EduTeams, an artificial intelligence-based information system for automating student group formation using the Edu2Com API, which considers MBTI personality types, skills, topic preferences, and gender balance. The system development employs Agile Kanban methodology to ensure flexibility and continuous improvement, while testing uses grey-box testing methods. Research results show that out of 67 identified features, 56 features (83.6\%) have been successfully implemented and tested. Comprehensive testing using 347 test cases achieved 100\% success rate with 89.42\% code coverage (line coverage) and 86.96\% function coverage. Edu2Com API integration successfully produces automatic group formation with 100\% success rate on 20 test cases. Non-functional testing across three browsers (Chromium, Firefox, Mobile Chrome) showed 100\% success with Lighthouse Performance score 98/100 and Accessibility 100/100. The EduTeams system has achieved good maturity level and is ready for production environment deployment, featuring multi-language support (Indonesian and English), role-based access control security, and optimal performance meeting modern software quality standards.\par
     
    \vspace{20pt}
	\raggedright\textbf{Keywords: collaborative learning, automated group formation, artificial intelligence, Agile Kanban, grey-box testing}
