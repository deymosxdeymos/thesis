	\large \bfseries \MakeUppercase{Abstract}\\
	\normalsize \normalfont {\thetitleEN}\\
	\normalsize \normalfont {\theauthor}\\
	\bigskip
	
	\normalsize \normalfont \justifying \singlespacing
	Collaborative learning is a vital component in modern education for developing students' interpersonal and problem-solving skills. However, manual group formation often results in skill imbalances, interpersonal conflicts, and unequal participation. This research develops EduTeams, an artificial intelligence-based information system for automating student group formation using the Edu2Com API, which considers MBTI personality types, skills, topic preferences, and gender balance. The system development employs Agile Kanban methodology to ensure flexibility and continuous improvement, while testing uses grey-box testing methods. Research results show that the majority of features have been successfully implemented and tested. Comprehensive testing achieved high success rates with adequate code coverage. Edu2Com API integration successfully produces automatic group formation as expected. Non-functional testing across Chromium, Firefox, and Mobile Chrome demonstrated good cross-browser portability and internationalization support, with Lighthouse scores meeting quality standards. Minor mobile interaction limitations were observed. The EduTeams system has achieved good maturity level and is ready for production deployment, featuring multi-language support (Indonesian and English), role-based access control security, and performance that meets modern software quality standards.\par
     
    \vspace{20pt}
	\raggedright\textbf{Keywords: collaborative learning, automated group formation, artificial intelligence, Agile Kanban, grey-box testing}
