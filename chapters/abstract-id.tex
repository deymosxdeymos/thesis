	\normalsize \normalfont \justifying \singlespacing
	Pembelajaran kolaboratif merupakan komponen vital dalam pendidikan modern untuk mengembangkan keterampilan interpersonal dan pemecahan masalah mahasiswa. Namun, pembentukan kelompok manual sering menghasilkan ketidakseimbangan keterampilan, konflik interpersonal, dan partisipasi yang tidak merata. Penelitian ini mengembangkan sistem informasi EduTeams berbasis kecerdasan buatan untuk otomatisasi pembentukan kelompok mahasiswa menggunakan API Edu2Com yang mempertimbangkan kepribadian MBTI, keterampilan, preferensi topik, dan keseimbangan gender. Pengembangan sistem menggunakan metodologi Agile Kanban untuk memastikan fleksibilitas dan kontinuitas perbaikan, sementara pengujian menggunakan metode grey-box testing. Hasil penelitian menunjukkan bahwa dari 67 fitur teridentifikasi, 56 fitur (83.6\%) telah berhasil diimplementasikan dan diuji. Pengujian komprehensif menggunakan 347 test cases menghasilkan 100\% tingkat keberhasilan dengan cakupan kode 89.42\% (line coverage) dan 86.96\% (function coverage). Integrasi Edu2Com API berhasil menghasilkan pembentukan kelompok otomatis dengan tingkat keberhasilan 100\% pada 20 test cases. Pengujian non-fungsional pada tiga browser (Chromium, Firefox, Mobile Chrome) menunjukkan 100\% keberhasilan dengan skor Lighthouse Performance 98/100 dan Accessibility 100/100. Sistem EduTeams telah mencapai tingkat maturity yang baik dan siap untuk penggunaan dalam lingkungan produksi dengan dukungan multi-bahasa (Indonesia dan Inggris), keamanan berbasis role-based access control, dan performa optimal yang memenuhi standar kualitas perangkat lunak modern.\par
